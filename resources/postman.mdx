The Buildmarkets Postman collection gives you ready-to-run requests organized into folders — one for each API domain. Import it, set three environment variables, and you're making live sandbox calls in under two minutes.

## Quick setup

<Steps>
  <Step title="Import the collection">
    Open the [Buildmarkets Postman Collection](https://documenter.getpostman.com/view/56251887/2sBY4QreKw) and click **Run in Postman** to import it directly into your Postman workspace.
  </Step>
  <Step title="Set environment variables">
    Create a new Postman environment and add these three variables:

    | Variable | Value |
    | --- | --- |
    | `baseUrl` | `https://dev-tapp-api.tappengine.com` — preset; note there is no `/v1` suffix, each request adds its own path |
    | `apiKey` | Your sandbox API key |
    | `apiSecret` | Your sandbox API secret |

    Select the environment from the dropdown in the top-right corner of Postman before sending any requests.
  </Step>
  <Step title="Run your first request">
    Open the **Market Data → Real-time price** request and click **Send**. It uses the preset `symbol` variable (`AAPL`), so it works before you have created any accounts.
  </Step>
</Steps>

## Collection contents

The collection is organized by API domain:

| Folder | Requests |
| --- | --- |
| **API Keys** | Generate, list, and revoke partner API keys |
| **Accounts** | Create an account, create an additional account for an existing user, list, get, update, close; balances and positions |
| **Account Tokens** | Create, list, and revoke account-scoped `tappacct_*` tokens |
| **Funding** | Link a bank account, list and remove ACH relationships, ACH deposits and withdrawals, funding activity |
| **Trading** | Place, list, get, modify, and cancel orders; execution reports |
| **Webhooks** | Create, list, get, update, and delete webhooks; send a test event; list delivery attempts |
| **Market Data** | Quotes, historical data, company profile, dividends, news, sectors and industries, security master, and options reference |
| **Documents** | List supported documents, upload, retrieve, email, and request a W-9 |

## Collection variables

The collection uses variables for resource IDs. After creating a resource, update the corresponding collection variable so subsequent requests in that flow reference it automatically:

| Variable | Set after |
| --- | --- |
| `accountId` | Creating an account |
| `orderId` | Placing an order |
| `webhookId` | Creating a webhook endpoint |
| `keyId` | Generating an API key |
| `achId` | Linking a bank account |
| `activityId` | Creating a deposit or withdrawal |
| `userId` | Creating an account, when adding additional accounts for the same user |
| `id` | Generic ID used by a few requests |

`symbol`, `underlying`, and `contract` come preset (`AAPL`, `AAPL`, and a sample option contract) so market-data requests run without setup.

<Tip>
  Use Postman's **Tests** tab to write a post-request script that automatically extracts the ID from each response and sets the corresponding collection variable. This lets you chain requests without manual copy-pasting.
</Tip>

## Switching environments

To switch from sandbox to production:

1. Create a new Postman environment
2. Set `baseUrl` to `https://api.tappengine.com` (no `/v1` suffix)
3. Enter your production API key and secret
4. Select the production environment from the dropdown before sending requests

<Warning>
  Production requests create real accounts and execute real trades. Confirm you have completed sandbox testing and received production access approval before switching environments.
</Warning>
